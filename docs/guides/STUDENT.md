# Student Guide

## Sign in

Learner portal → **Student**  
`POST /api/v1/auth/student/login` + tenant slug

## Learning loop

1. Open **dashboard** / **courses** / **lessons**.
2. Complete interactive blocks; progress saves automatically.
3. Submit **homework** before the due date.
4. Take **quizzes/exams**; review **results**.
5. Book a **tutor** when slots are open; join classroom at session time.
6. Earn **certificates** when the school issues them.
7. Read **notifications** (assignments, reminders, cancellations).

APIs: `/api/v1/learner/student/*` and shared `/api/v1/learner/*`.

## Tips

- Switch language with the portal locale control (EN/AR).
- Join tutoring a few minutes early.
- If login fails, confirm you have the correct school **slug**.
